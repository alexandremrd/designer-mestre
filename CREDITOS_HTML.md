# Créditos — fontes do Módulo HTML v2

O Módulo HTML (`modulos/html.md`), o `assets/qa_html.py` e as melhorias do `assets/base_lp.html` foram escritos a partir do estudo destes projetos da comunidade, salvos em `a pasta de pesquisa do autor`. Nenhum código foi copiado literalmente; as técnicas foram adaptadas e reescritas.

| Projeto | Licença | O que foi aproveitado |
|---|---|---|
| onepage-skill (wjhuang88) | MIT | Modo página-relatório: decisões antes do conteúdo, um padrão visual por capítulo, cores semânticas fixas, regras de grid/responsivo/impressão, checklist de qualidade |
| screenshot-to-code (Abi Raja) | MIT | Modo recriar de print/vídeo: fidelidade total, texto exato, extração ou geração de imagens, vários prints, vídeo funcional com dados mockados, verificação por screenshot desktop+mobile |
| bolt.diy (StackBlitz e contribuidores) | MIT | Planejar em 2–4 linhas antes de codar, arquivo completo sem placeholders, grade de 8 px, paleta de 3–5 cores, WCAG AA, microinterações, componentes com estados |
| prompts.chat (f/awesome-chatgpt-prompts) | CC0 (prompts) / MIT (código) | Estrutura de LP que converte, tipografia (Butterick), Core Web Vitals, SEO técnico, QA visual e cross-browser, varredura de placeholders antes de publicar |
