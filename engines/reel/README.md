# reel skill

Claude Code skill that **cuts and edits a reel** (9:16) from raw footage of someone talking, with no panel and no
choices: send the video, it cuts and edits.

- **Cut**: removes silences, breaths, "éé", stutters, mistakes, restarts and repetitions. Sound-based cut (volume +
  timbre, calibrated to the recording level), edges at the energy valley, J/L cuts and a transcript check of every
  splice. It is the cut engine approved in production (Oct/2026), copied intact.
- **Edit**: the **VSL engine with animated interface** — the camera alternates full screen with punch-in and split screen
  with the presenter in a card; each spoken keyword becomes an interface piece that enters exactly on the word;
  caption that follows the mouth; lean sound effects; audio at −14 LUFS. It is the same kit (untouched) and the same
  rules that produced the approved reference reel; reassembled, the example comes out pixel-identical.

Delivers a verified `render/reel-v1.mp4` (`VERIFY.md`, frame sheet, safe zone, LUFS) and iterates on request.

## Install
```bash
git clone https://github.com/Felpborges/skill-reel.git ~/.claude/skills/reel
```
Then, in Claude Code, just send the video and ask "edit this reel" (or `/reel`).

## What the machine needs
| For | Tool |
|---|---|
| cut and transcription | `ffmpeg`, `whisper-cli` (whisper.cpp) + model `ggml-large-v3-turbo.bin` in `~/.cache/whisper-cpp/` (or `WHISPER_MODEL`), Python 3 with `numpy` |
| framing, safe zone, caption that follows the mouth | `opencv-python-headless` (and, for fine tracking, `mediapipe` in a Python pointed to by `VSL_PYTHON`) |
| composition and render | Node 20+ (`prepare.sh` installs `hyperframes` 0.7.109, `gsap` 3.14.2 and `playwright`), Google Chrome (or `CHROME=<executable>`) |

`python3 cut/scripts/0-check.py` tells what is missing and how to install it. Mac: `brew install ffmpeg whisper-cpp`.

## How it works (the flow `SKILL.md` follows)
1. **Cut** (`cut/`): take map by energy → editorial choice of the *keeps* → transcript that does not hide
   fillers → cut engine → check (text, repetitions, splices, pauses). Outputs `clean.mp4` + `cut_words.json`.
2. **VSL engine** (`template/`): `prepare.sh` (9:16 camera with the voice, transcript, mouth tracking) → corrected
   transcript → measured framing (`vsl.json`) → real material with sources (`SOURCES.md`) → beat map →
   `src/beats.js` (only `K.*` calls anchored to the speech) → lint → snapshots → safe zone → render → final audio →
   `verify.py` → `reel-v1.mp4`.

## Structure
```
SKILL.md              the flow Claude follows
house-rules.md     R1–R11 (face never covered, sparing SFX, real material, no clipped word, −14 LUFS…)
STYLE.md             the VSL engine spec (layouts, motion, caption, pieces, sound, acceptance, production lessons)
skin.json             native values (fonts, colors, invariants)
cut/                cut engine: CUT.md · references/ROUGH-CUT.md · scripts/ · example/ (approved reference)
template/               VSL engine: kit/ · assemble.mjs · prepare.sh · tools/ · example/ (the whole approved reel)
tools/          prepare.py · face.py · anchors.py · verify.py · safe-zone.py · crop.py · final-audio.sh
attachments/               reference frames and the color before × after
```
